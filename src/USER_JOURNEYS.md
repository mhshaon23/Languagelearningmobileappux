# User Journeys - Speallu

## Overview
This document maps out the key user journeys for the Speallu mobile app wireframe. Each journey represents a common user flow through the application.

---

## Journey 1: New User - First Learning Session

**User Goal:** Complete their first lesson and establish a learning routine

**Steps:**
1. **Launch App** → Lands on Home Screen
2. **View Welcome Message** → Sees personalized greeting and empty streak calendar
3. **See Daily Goal** → Notices progress bar at 0/5 lessons
4. **Notice Quick Actions** → Sees Badges and Schedule buttons for later exploration
5. **Tap "Continue Learning" Card** → Card shows "Start Your First Lesson" with beginner badge
6. **Auto-navigate to Games Screen** → Directly jumps to first lesson quiz (no additional navigation needed)
6. **Switch to Lessons Tab** → Views lesson path with first lesson unlocked
7. **Select First Lesson** → Opens lesson (blue border indicates current)
8. **Auto-navigate to Games Screen** → Begins interactive quiz
9. **Complete Questions** → Answers 10 questions (progress bar fills)
10. **Return to Home** → Sees updated daily goal (1/5 lessons complete)
11. **View Streak Update** → First day marked on streak calendar

**Key Screens:** Home → Lessons → Practice → Home

**Success Metrics:**
- Lesson completion rate
- Time to first lesson completion
- Return to app within 24 hours

---

## Journey 2: Daily Learner - Maintaining Streak

**User Goal:** Maintain their learning streak by completing daily goal

**Steps:**
1. **Open App (Day 7)** → Home Screen shows 6-day streak
2. **Check Streak Calendar** → Sees 6 consecutive days filled
3. **Review Daily Goal** → Currently at 2/5 lessons (40% complete)
4. **View Continue Learning Card** → Shows "Lesson 23: Food Vocabulary" with progress "5/10 completed"
4. **Tap Continue Learning** → Resumes in-progress lesson
5. **Complete 3 More Lessons** → Uses Games Screen for each
6. **Check Progress Tab** → Views daily goal completion (5/5)
7. **See Streak Updated** → 7-day streak unlocked with visual celebration
8. **View Weekly Chart** → Progress tab shows consistent daily activity
9. **Check New Achievement** → Unlocked "Week Warrior" badge

**Key Screens:** Home → Practice (×3) → Progress → Home

**Success Metrics:**
- Streak retention rate
- Daily active users (DAU)
- Lessons per session
- Achievement unlock rate

---

## Journey 3: Achievement Hunter

**User Goal:** Unlock achievements and badges

**Steps:**
1. **Navigate to Progress Tab** → Views current stats and achievements
2. **See Locked Achievements** → 3 earned (gold), 3 locked (gray)
3. **Tap Quick Action "Achievements"** → From Home Screen
4. **Review Achievement Requirements** → Understands what's needed
5. **Navigate to Lessons** → Selects specific lesson category
6. **Filter by Category** → Uses category chips (Basics, Grammar, Vocabulary)
7. **Complete Category Lessons** → Focuses on "Basics" category
8. **Return to Progress** → Sees new achievement unlocked
9. **Share Achievement** → (Future: social sharing feature)

**Key Screens:** Progress → Home → Lessons → Practice → Progress

**Success Metrics:**
- Achievement completion rate
- Category completion rate
- User engagement time

---

## Journey 4: Struggling Learner - Review & Practice

**User Goal:** Review difficult content and improve weak areas

**Steps:**
1. **Open App** → Home Screen shows stalled progress
2. **Notice Progress Bar** → Stuck at 60% on current lesson
3. **Navigate to Lessons** → Views lesson path
4. **See Current Lesson** → Blue border, partial progress bar (66%)
5. **Review Completed Lessons** → Taps green checkmark lesson
6. **Access Lesson Details** → Reviews what was learned
7. **Use Quick Action** → Taps "Practice" from Home
8. **Enter Practice Mode** → Random review questions from all lessons
9. **Use Audio Support** → Taps speaker icon for pronunciation
10. **Use Voice Input** → Taps microphone for speaking practice
11. **Complete Practice Session** → Returns to Home
12. **See Updated Stats** → Progress tab shows improved performance

**Key Screens:** Home → Lessons → Practice → Progress

**Success Metrics:**
- Lesson retry rate
- Practice mode usage
- Audio feature engagement
- Performance improvement over time

---

## Journey 5: Explorer - Discovering Content

**User Goal:** Browse and explore available lessons and content

**Steps:**
1. **Navigate to Lessons Tab** → Views full lesson path
2. **Use Search Bar** → Searches for specific topic
3. **Filter by Category** → Taps category chips to filter
4. **Switch Categories** → Cycles through All, Basics, Grammar, Vocabulary
5. **Review Lesson Progression** → Sees locked lessons below current
6. **Understand Unlock Requirements** → Learns lessons unlock sequentially
7. **Check Lesson Details** → Views lesson name, level, and progress
8. **Plan Learning Path** → Identifies next 3-4 lessons to complete
9. **Return to Home** → Prepares to continue structured learning

**Key Screens:** Lessons → Lessons (category filtering)

**Success Metrics:**
- Search usage
- Category filter engagement
- Lesson preview interactions
- User retention after browsing

---

## Journey 6: Progress Tracker

**User Goal:** Monitor learning statistics and track improvement

**Steps:**
1. **Navigate to Progress Tab** → Main analytics view
2. **Review Stats Grid** → Sees 3 key metrics (days, lessons, points)
3. **Analyze Weekly Chart** → Views bar chart of daily activity
4. **Switch Time Period** → Changes from "Week" to "Month" view
5. **Review Achievements** → Scrolls to achievement grid
6. **Check Goal Progress** → Views current goal status (80% complete)
7. **Compare to Past Performance** → Identifies trends and patterns
8. **Navigate to Home** → Motivated to continue learning
9. **Set New Personal Goal** → (Future: custom goal setting)

**Key Screens:** Progress → Progress (time period toggle)

**Success Metrics:**
- Progress tab engagement
- Chart interaction rate
- Goal completion rate
- Session frequency

---

## Journey 7: Settings Manager

**User Goal:** Configure app preferences and manage account

**Steps:**
1. **Navigate to Settings Tab** → Main settings view
2. **Review Account Section** → Personal information and profile
3. **Check Notifications** → Review notification preferences
4. **Toggle Settings** → Enable/disable push notifications
5. **Review Language Options** → Check interface language settings
6. **Tap Send Feedback Button** → Opens feedback dialog
7. **Select Emoji Rating** → Choose feeling (Terrible to Amazing)
8. **Select Feedback Category** → Bug Report, Feature Request, or General
9. **Write Optional Comments** → Share detailed thoughts
10. **Submit Feedback** → See confirmation message
11. **Access Help & Support** → Browse help resources
12. **Check About Section** → View app version and information
13. **Return to Home** → Continue learning with updated preferences

**Key Screens:** Settings → Feedback Dialog → Settings → Home

**Success Metrics:**
- Settings engagement rate
- Notification opt-in rate
- Feedback submission rate
- Feedback quality (text provided)
- Help resource access
- User preference customization

---

## Journey 8: Post-Lesson Feedback Provider

**User Goal:** Provide feedback after completing multiple lessons

**Steps:**
1. **Complete Practice Lesson** → Finish lesson quiz
2. **See Completion Animation** → Visual success feedback
3. **Automatic Feedback Prompt** → Triggered every 5 lessons
4. **View "How was this lesson?" Dialog** → Focused on lesson experience
5. **Select Emoji Rating** → Quick emotional response
6. **Write Optional Comments** → Share specific lesson feedback
7. **Submit or Skip** → Choose to provide or dismiss feedback
8. **Return to Practice** → Continue learning flow
9. **Complete Next Lesson** → Maintain momentum

**Key Screens:** Practice → Feedback Dialog (auto-triggered) → Practice

**Success Metrics:**
- Feedback response rate (vs. skip rate)
- Average ratings per lesson type
- Feedback frequency
- User engagement after feedback prompt
- Lesson completion momentum maintained

## Key User Flows Summary

### Primary Navigation Paths:
```
Home ←→ Lessons ←→ Practice ←→ Progress ←→ Settings
  ↓         ↓          ↓          ↓          ↓
[Start] [Browse]  [Learn]   [Track]  [Configure]
```

### Common Entry Points:
1. **Daily Habit Users** → Home → Continue Learning → Practice
2. **Explorers** → Lessons → Browse → Practice
3. **Trackers** → Progress → Review → Home → Practice
4. **Achievers** → Progress → Achievements → Lessons → Practice
5. **Feedback Providers** → Settings → Send Feedback → Submit

### Critical Moments:
- **First Lesson Completion** (Day 1) - High drop-off risk
- **7-Day Streak** (Day 7) - Key retention milestone
- **First Locked Lesson** - Understanding progression system
- **Daily Goal Achievement** - Habit formation reinforcement
- **Every 5th Lesson** - Feedback prompt opportunity
- **First Feedback Submission** - User voice engagement

### Cross-Journey Patterns:
- **Games Screen** is central to all journeys
- **Home Screen** serves as mission control
- **Progress Tab** provides motivation and validation
- **Lessons Tab** enables exploration and planning
- **Settings Screen** provides app configuration and preferences
